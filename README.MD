# 🌌 Callisto

Callisto is an experimental Android connection tool focused on privacy, stability, and simple access control in difficult network conditions.

> ⚠️ This project is currently in alpha. Use it for testing and development purposes.

## ✨ Features

- 🔐 Privacy-focused connection mode
- 🌍 Country selection support
- ⚡ Fast connection search
- 🔁 Improved reconnect behavior
- 🧩 Split tunneling support
- 📱 Android VPN mode
- 📄 Built-in connection logs
- 🛠️ Lightweight settings panel
- 🚫 No unnecessary tracking features

## 📦 Installation

1. Download the latest APK from the Releases section.
2. Install it on your Android device.
3. Allow VPN permission when requested.
4. Open the app and choose your preferred connection options.
5. Tap Connect.

## ⚙️ Basic Usage

- Use **Country** to select your preferred route.
- Use **Fast Mode** for quicker connection attempts.
- Use **Split Tunneling** to choose which apps use the connection.
- Check **Logs** if the connection does not start correctly.

## 🧪 Status

Callisto is under active development.  
Some features may change, improve, or be removed in future versions.

## 🔒 Privacy

Callisto is designed to avoid collecting personal data.  
Connection logs are intended for local troubleshooting only.

## 🛠️ Build

This project can be opened with Android Studio.

Recommended setup:

- Android Studio latest stable version
- JDK 21
- Gradle 9.3
- Android Gradle Plugin 9.x

For release builds, sign the APK with your own keystore.
